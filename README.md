# Business Lead Intelligence Pipeline

A Python-based data automation pipeline that collects business data from a public API, validates and normalizes records, removes duplicates, and generates structured reports.

## Project Status

In development

## Planned Features

- API data collection
- Pagination handling
- Data validation
- Data cleaning and normalization
- Duplicate detection
- Structured data storage
- CSV and Excel report generation
- Error handling and logging
- Automated tests

## Tech Stack

- Python
- Requests
- Pandas
- OpenPyXL
- Pytest

## Purpose

This project demonstrates a practical Python automation workflow for collecting, processing, validating, and reporting structured business data.
